# 🎯 My Quiz App
An interactive Quiz App built with Next.js & React. Play quizzes, track your score with a timer, get instant results, and enjoy a clean responsive UI.

### 🔗 Live Demo
👉 https://my-quiz-app-2ywy.vercel.app/

## ✨ Features
- 📝 Multiple Choice Questions
- ⏱️ Timer for each question
- 📊 Instant Score Tracking
- ✅ Instant Right / Wrong Feedback
- 📱 Fully Responsive - Mobile & Desktop
- 🎨 Clean & Modern UI

## 🛠️ Tech Stack
- **Next.js** - React Framework
- **React** - UI Library
- **JavaScript** - Logic
- **Tailwind CSS** - Styling
- **Vercel** - Deployment

## 🚀 How To Run Locally
```bash
# 1. Clone the repo
git clone https://github.com/akankshama97/My_Quiz_App.git

# 2. Go to folder
cd My_Quiz_App

# 3. Install packages
npm install

# 4. Run the app
npm run dev
